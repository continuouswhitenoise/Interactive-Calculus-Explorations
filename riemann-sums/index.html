How to read the sums: Lower and upper Darboux sums use the infimum and supremum on each subinterval. Here those extrema are estimated by sampling the function at 101 points per subinterval, so they are not certified bounds for every function. Left-, right-, and midpoint sums use the function value at the named sample point. For continuous functions, exact lower and upper Darboux sums squeeze toward the definite integral as the partition is refined.
