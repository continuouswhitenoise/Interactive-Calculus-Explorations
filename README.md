# Regular Polygon Pi Approximation

An interactive geometric simulation approximating π using inscribed and circumscribed regular polygons (n = 3 to 60).

## Features
* **Dual-View Geometry**: Simultaneously compares inscribed (teal) and circumscribed (orange) polygons against a unit circle.
* **Interactive Controls**: Drag the slider or hit Play/Pause to watch convergence in real time.
* **Precise Readouts**: Displays exact area and perimeter metrics alongside true values of π and 2π.
