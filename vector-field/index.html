Mathematical setup

r(t) = (2 cos t, sin t)
0 ≤ t ≤ 2π
F(x,y) = (−y, x)
R(s) = r(t(s))
T(s) = R′(s)
N(s) = (−T₂(s), T₁(s))
Work density = F(R(s)) · T(s)
Flux density = F(R(s)) · N(s)

The curve is sampled numerically to build an arc-length lookup table. The slider uses that table to move approximately uniformly with respect to arc length. The displayed work and flux values are pointwise densities, not the total line integrals.

Work and flux along the curve

Each graph shows its density as a function of arc length s. The shaded region follows the moving point, showing the signed accumulated area from the start of the curve to the current position.

Area above the horizontal axis contributes positively; area below contributes negatively. The accumulated values approximate the corresponding line integrals along the portion of the curve already traversed. At the end of a closed traversal, these approach the total work and total outward flux for this chosen orientation.
